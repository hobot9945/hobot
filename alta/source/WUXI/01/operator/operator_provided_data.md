# Данные, подтвержденные оператором

## Инвойс SKI260513DG01 от 13.05.2026
- **Проблема:** В оригинале документа указаны неверные итоговые стоимости по строкам при заданных количестве и цене.
  - Поз. 1: Кол-во 4000 * Цена 7.00 = 28000.00 (в оригинале 24500.00)
  - Поз. 2: Кол-во 1000 * Цена 7.00 = 7000.00 (в оригинале 10500.00)
- **Решение:** По указанию оператора количество (4000 и 1000) считается верным. Стоимости пересчитаны.
