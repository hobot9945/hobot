# Правила расчета и верификации весов ДТ (dt_rules.md)
Используется совместно с `alta\prompt\{stage_1\primary_schema.md | stage_2\dt_fields_schema.md | stage_3\dt_check.md`.

## 1. `weight_rules` - Алгоритм расчета весов по товарам
Детерминированные правила расчета и верификации весов брутто и нетто по товарам. Используется на
Этапе 1 (для генерации primary.md при наличии "ленивого" упаковочного листа) и на Этапе 3 (для верификации готовой ДТ).

### Входные параметры:
- $G_{total}$ — общий вес брутто по накладной/PL.
- $N_{total}$ — общий вес нетто по накладной/PL.
- $Q_i$ — количество штук $i$-го товара.
- $W_{phys, i}$ — физический вес одного устройства $i$-го товара из технического описания.

### Шаг 1: Расчет чистого веса оборудования (Bare Net)
Для каждого товара рассчитывается чистый вес без упаковки:
$$N_{bare, i} = Q_i \times W_{phys, i}$$
Сумма всех чистых весов:
$$N_{bareTotal} = \sum N_{bare, i}$$

### Шаг 2: Верификация веса нетто поставщика
1. **Нижний порог:** Суммарный вес нетто по данным поставщика ($N_{total}$) должен быть больше или равен рассчитанному 
   нами по техничкам ($N_{bareTotal}$):
   $$N_{total} \ge N_{bareTotal}$$
   *Если условие нарушено — остановить процесс, выдать ошибку (физический вес приборов превышает заявленный нетто).*

2. **Верхний порог (Правило 8%):** Суммарный вес нетто поставщика не должен превышать наш расчетный чистый вес более чем 
   на 8%:
   $$N_{total} \le N_{bareTotal} \times 1.08$$
   *Если условие нарушено — выдать критическое предупреждение `[WARNING] КРИТИЧЕСКИЙ ВЕС ТАРЫ (КАРАУЛ!)` в итог файла и 
   известить оператора (возможен избыточный вес упаковки или ошибка в техничке).*

### Шаг 3: Распределение веса индивидуальной упаковки (нетто)
Разница между заявленным нетто и чистым весом приборов ($D_{pkg} = N_{total} - N_{bareTotal}$) распределяется 
пропорционально чистому весу приборов:
$$N_{calc, i} = N_{bare, i} + \left( D_{pkg} \times \frac{N_{bare, i}}{N_{bareTotal}} \right)$$
Значение $N_{calc, i}$ округляется до 3 знаков после запятой.

### Шаг 4: Распределение веса внешней тары (брутто)
Разница между брутто и нетто распределяется пропорционально расчетному нетто $N_{calc, i}$:
$$G_{calc, i} = N_{calc, i} \times \frac{G_{total}}{N_{total}}$$
Значение $G_{calc, i}$ округляется до 3 знаков после запятой.

### Шаг 5: Балансировка округления
Если сумма округленных значений $\sum N_{calc, i}$ или $\sum G_{calc, i}$ отличается от $N_{total}$ или $G_{total}$:
- Разница (остаток) прибавляется или вычитается из веса **самого тяжелого (первого по весу) товара** поставки, чтобы 
  итоговая сумма сошлась с точностью до грамма.


## 2. `aggregation_forbidden_list` - Товары, запрещенные к группировке
Согласно постановлению № 257 следующие группы товаров запрещено агрегировать по коду ТН ВЭД, то есть представлять
отдельными позициями:
- 22 - Алкоголь
- 27, 28, 29 -Нефтепродукты и химия
- 4011, 4012 - Шины
- 8471 - Компьютерная техника
- 8418, 8422, 8450, 8508, 8509, 8516 - Бытовая техника
- 8517, 8521, 8525, 8528 - Электроника и связь
- 87 - Транспорт
- 89 - Плавсредства

Список не исчерпывающий, при сомнениях — запрос оператору. Характерными признаками служат также:
- разные разрешительные документы (Сертификаты/Декларации соответствия),
- наличие серийных номеров или IMEI,
- разные производители,
- существенные технические различия,
- наличие маркировки.

Такие товары должны быть представлены отдельными элементами массива, см. `### 3.16 Массив товаров goods[]`.
