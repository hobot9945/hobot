# Дорожная карта проекта Delta

## Суть
Переход от системы промптов (`alta`) к полноценному приложению (Rust + SurrealDB) для менеджеров ВЭД.

## Этапы развития

**Этап 1. CLI и База Данных (Текущий)**
- Создание структуры `Shipment` (единый источник истины без дублирования).
- CLI-утилита для парсинга первичных документов и загрузки нормализованных фактов в БД.

**Этап 2. Ядро и логика**
- Обработка конфликтов (пересечение данных в разных документах).
- Расчет производных значений (веса, стоимости, распределение по товарам).

**Этап 3. Графический интерфейс (GUI)**
- Рабочее место менеджера ВЭД.
- Ручная правка данных структуры `Shipment`.

**Этап 4. Обратная генерация**
- Формирование готовых первичных документов (Инвойс, Упаковочный и др.) и данных для ДТ на основе БД `Shipment`.
