
### 1.1 HJSON
Хобот использует собственное расширение формата JSON. HJSON позволяет использовать в любом месте JSON-структур, в том
числе внутри строковых литералов, байтовый управляющий символ перевода строки (физический перевод строки), экранированный
обратным слэшем.

**Пример:**
"строка один\n\
строка два"

**ВАЖНО:**
1. Символ `\` должен быть последним на физической строке кода.
2. Сразу за ним должен идти настоящий разрыв строки (байт 0x0A).
3. **ВСЕГДА** внутри текстовых строк после стандартного в JSON перевода строки `\n` добавляй `\` + физический
   перевод строки. Это улучшает читаемость внутри кодового блока.
